# Guía de uso de `/ia/tasks`

Crea **un archivo `.md` por tarea** (ejemplo: `2026-03-ajuste-matricula.md`) con:

1. **Objetivo**
   - Qué problema se resuelve y criterio de éxito.

2. **Alcance técnico**
   - Componentes, hooks, rutas y archivos involucrados.

3. **Restricciones**
   - Qué no se debe tocar (contratos, flujos, layout, etc.).

4. **Validación**
   - Pruebas/manual checks mínimos para aceptar la tarea.

Usa ese archivo como input directo para prompts de Codex para mantener contexto, límites y trazabilidad.
